# Lilypad Lake

A relaxing pond fishing game for the desktop browser. **Play it:** https://headclanker.github.io/lilypad-lake/

## How to play

1. Move the mouse to drop your float in the pond.
2. Hold still. A fish creeps up and nibbles.
3. When the float plunges, flick the mouse **up** (or click) to hook it.
4. Catch the **Wanted** fish for +10 seconds. Watch out for the old boot (−5 seconds).

You have 60 seconds. Your best score is saved in your browser.

**Keys:** `Space` strike · `M` sound on/off · `P` pause

## Running it locally

It's a single `index.html` file with no build step. Open it in a browser, or serve the folder with any static file server.
